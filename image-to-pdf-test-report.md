# Image to PDF Generator v1.0 — Test Report & Product Listing

**File:** `index.html` (22.9 KB — limit 150 KB) · single file, all CSS/JS inline, zero external assets, zero network calls, no localStorage, no service workers, no permissions, no parent-window access. Safe for the sandboxed Wix iframe. The PDF is produced by a small hand-written PDF engine inside the page (PDF 1.4, JPEG/DCTDecode image streams) — no libraries, no backend, no API keys. No feature of this app requires a server.

## What it does
Add up to 50 images (PNG, JPEG, WebP, BMP, GIF — first frame — or AVIF, ≤ 25 MB each); each becomes one PDF page in the order shown (rearrange with ↑ ↓, remove with ✕). Page size A4 / Letter / Fit-to-image, orientation Auto / Portrait / Landscape, margins 0–25 mm, image quality 60–100, custom file name. Transparency is flattened onto white. The result panel reports page count and exact file size before download.
